Windows向け

Codex Panda Pet の使い方

デスクトップにパンダさんが住みつく、小さなローカルアプリです。 ネット通信なしで動きます。

起動方法

  1. ZIPを解凍します。
  2. フォルダの中にある Start-PandaPet.bat をダブルクリックします。
  3. デスクトップにパンダさんが表示されます。

操作方法

  • 左クリックしてドラッグ: パンダさんを移動
  • クリック: びっくりリアクション
  • 右クリック: サイズを切り替え
  • マウスホイール: 細かく拡大・縮小
  • 終了: パンダさんのウィンドウを選んで Alt + F4

パンダさんがすること

  • ころころ転がる
  • 笹をもぐもぐする
  • 寝る
  • ゆらゆらする
  • ぽよんと跳ねる
  • たまに「パンダさんパワー！」と言う

注意

  • 現在はWindows向けです。Macには対応していません。
  • Windowsの保護メッセージが出た場合は、内容を確認してから実行してください。
  • ファイル名やフォルダ構成を変えると、画像が表示されない場合があります。
